# Changes – IPAM

## 0.1.0 – 2026-11-09

First version.

### New
- Add subnets (IPv4 and IPv6) with a card and usage bar.
- The address list fills itself from DNS64 and the neighbour table; you add name, note and reservation by hand.
- Unknown devices show up as "new" and can be acknowledged or ignored.
- Local API under `/api/ipam`.
